# 潮汐 · Bitget 超短线扫描器

网页：https://ksjlh011-creator.github.io/bitget-perp-scanner/

独立中文iPhone网页，Bitget V2公开API，无密钥、不下单、无后台监控。只有点击扫描才读取真实行情。严格筛选24小时USDT成交额前40、正常交易的USDT永续合约，包含排名内的BTC、ETH和山寨；不强行加入排名外币种。

## 导出本次完整数据

扫描结束后点击网页“导出完整数据”，下载包含40币×5周期×100根已收盘K线的JSON，附报价、24h成交额、Bitget时间、逐币策略结果及净RR。数据错误独立标红，不属于普通等待；不完整文件名含INCOMPLETE。iPhone下载步骤与字段说明见[EXPORT.md](EXPORT.md)。行情与策略/回放窗口统一为100根。

## 结构止损与计划仓位

新增账户权益输入、6/10/15根5m有效结构比较、ATR缓冲参数和风险说明。初始0.5倍ATR为待验证参数，与0.3/0.8/1.0做真实历史对照，不自动选最佳。止损确定后重算净RR；账户权益未填则只观察。按双边费用及滑点计算单位止损风险，数量向下取整，单笔计划亏损≤权益1%，名义金额≤1倍权益。跳空等可能突破计划损失。详见[RISK.md](RISK.md)。

## 当前策略

4H/1H趋势必须一致，15m顺势回踩收复，随后5m确认，再由1m辅助区间入场。15m与5m量能门槛均为前20根均量1.5倍，保留EMA20/50及斜率规则，不降低标准以增加信号。单独突破或反转不再触发入场。

第一、第二止盈都必须来自已确认的真实摆动结构；按区间最差价格计算，第一止盈扣除双边手续费及滑点后的净盈亏比也须≥2:1。缺结构、缺量能或未确认一律重点观察/观察/等待；观察不展示可执行入场价位。信号超过1分钟确认有效期自动降为观察，不自动联网。

“重点观察”只用于结构、15m/5m量能、5m企稳和风控均通过但仍缺1m触发或报价位置的候选，绝不等于可入场。每币提供失败原因和16项状态，本次扫描显示通过/失败/未评估计数；列出最多5个已具备大周期同向及15m结构的观察候选，重点观察优先，其后按通过项数排序，不是概率。形态不同的结构判断保留OR关系，统计不是互斥漏斗。

详见[STRATEGY.md](STRATEGY.md)中的精确规则、短线止损/目标范围、回测执行模型与限制。

## 本地与验证

Node.js 22+，无需安装第三方依赖：

```sh
npm test
npm start
# 本地 http://localhost:8080
npm run verify:api
npm run backtest
```

`verify:api`真实请求服务器时间、当前成交额前40、五周期K线及各币报价，检查CORS响应头并输出逐币条件和总计。`backtest`请求官方历史K线，BTC/ETH/SOL/AAVE最近7天逐分钟回放，比较零/默认/双倍成本，保存原始数据与报告到reports。测试夹具仅位于tests，绝不作为实时行情。

## 限制

当前历史评估只覆盖4个指定币种7天，存在选样/幸存者偏差，不是历史全市场动态前40回测。误报代理为结束交易净亏损/持平比例，零成交时未知。未来价格仅用于成交后评价；未结束交易不计胜负。同分钟双触先止损，跳空不利成交，T1/T2各50%、最长120分钟；网页不执行任何退出。

默认单边手续费0.06%、滑点0.05%，不包含资金费、超预期冲击或真实历史盘口队列。回测不能证明盈利。CORS响应头检查通过不代表所有地区和设备都能连接Bitget；iPhone Safari实机验收仍需在可达网络完成。所有历史证据见[VALIDATION.md](VALIDATION.md)。与pusi-overseas-leads没有代码、远端或部署目标共享。
